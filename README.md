# pair_trading
pair trading backtest

Cleaned financial data from Bloomberg Terminal and Yahoo Finance, tested co-integration by performing ADF test between MU and AMD up to 10% significance level.
Developed mean-reversion trading strategy using z-score with rolling mean and standard deviation, backtested 6-month trading performance using Python.
Achieved an annualized return of 19.23% with Sharpe ratio of 1.334.
